# world/assets

El mundo es procedural (geometrías de three.js): no hay modelos ni texturas
remotas, para que cargue rápido y funcione con conexión limitada en eventos.
`palette.ts` define los colores. Si se incorporan modelos (por ejemplo GLB de
Culpeo y la chancha rosa), deben quedar aquí, optimizados (< 300 KB cada uno).
